YOUR FITTING AWAITS

Ready to open the closet?

Get the official release, install both pieces, and enter the game through VanillaFixes.

Get the latest release ↗

For the supported Windows WoW 1.12.1 client, build 5875. Requires VanillaFixes and VanillaHelpers.dll.

  1. 01

    Download the release

    Use the latest ZIP from the official Saurek’s Closet GitHub repository. Fully close the game before installing.

  2. 02

    Place both pieces

    Copy the SaureksCloset folder to Interface/AddOns/ and SaureksCloset.dll beside WoW.exe.

  3. 03

    Enable and enter

    Add SaureksCloset.dll to dlls.txt after VanillaHelpers.dll. Launch through VanillaFixes, enable the addon, then type /closet.

The DLL is required. After replacing it, fully restart the game; a UI reload will not load a new DLL. Read full installation instructions ↗
